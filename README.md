# Agent Jinglue · 经略

> 把"三省六部 AI 治理体系"做成一套普通人能用的多业务工作台——王朝版图看业务全局，京城衙署办具体事务，皇帝（你）只管批红。本仓库收录经略的产品设计、需求说明、可行性方案与可点击原型。

## 经略是什么

如果你同时用多个 AI 工具（Claude Code / Codex / ZCode / DSH……）打理多条业务线——工作、视频、学习、长期项目——大概经历过三件事：

1. **交办靠打字**：每次都要重新解释任务背景，AI 记不住上一单的验收标准
2. **全局看不见**：哪条业务推进到哪、哪些事卡在等审批，只能靠翻聊天记录
3. **审批靠自觉**：AI 顺手就把该你拍板的事办了，事后才发现

经略的答案是一套**朝廷隐喻的个人工作台**：

| 隐喻 | 实体 | 你在上面做什么 |
|---|---|---|
| **王朝版图** | 业务全景 | 行省=业务大类、府州=具体项目/主题、县=可独立验收的办理节点；点开地图就是每条业务的进展 |
| **京城衙署** | 工作界面 | 内阁票拟、中书草诏、门下封驳、六部办理、御史台监察——18 处衙署各管一段流程 |
| **御前** | 审批中心 | 该你批的事项集中呈现：批准绑定案号、版本和范围，不批不动 |
| **国史馆** | 沉淀复用 | 办完的事提炼成"熟地"县志，下次同类任务开局即有方法 |

核心原则与 [agent-government](https://github.com/Akao1/agent-government) 一致：**拟票者不批红**（AI 只拟方案，选择权永远在人）、**审批绑定范围**（每次批示绑定案号/版本/范围，不搞一揽子授权）、**小事直达**（闲聊直答不建任务，不把每次对话升格成朝廷大典）。
